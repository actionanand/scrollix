Data Entry Guide

Google Sheet Columns

Col Field Required Description
A S No Yes Serial number (auto-increment)
B Type Yes Content type (see types below)
C URL Yes Video ID or full URL depending on type
D Protected Yes "Yes" to require login, "No" for public
E Title No Display title for the content
F Desc No Description text
G Start Time No Start time in seconds (YouTube only)

Supported Types

youtube

Standard YouTube video

URL column: K6o9JTcPgOA
Actual URL: youtube.com/watch?v=K6o9JTcPgOA

✅ Start Time supported (column G, in seconds)

youtube-short

YouTube Shorts video

URL column: WcLbw92V4qk
Actual URL: youtube.com/shorts/WcLbw92V4qk

instagram

Instagram post or reel

URL column: DXHprmqgQQK
Actual URL: instagram.com/p/DXHprmqgQQK/

facebook

Facebook video or reel (using reel ID)

URL column: 1646510169815130
Actual URL: facebook.com/reel/1646510169815130

facebook-reel

Facebook reel (same handling as facebook)

URL column: 1646510169815130
Actual URL: facebook.com/reel/1646510169815130

facebook-share

Facebook share link (auto-resolved to video/reel)

URL column: https://www.facebook.com/share/v/1Dp1wqwvkX/
Or: https://www.facebook.com/share/r/1B5RTTQrfZ/

ℹ️ Paste the full share URL. It will be resolved automatically.

dailymotion

Dailymotion video

URL column: x5jnrro
Actual URL: dailymotion.com/video/x5jnrro

vimeo

Vimeo video

URL column: 360071854
Actual URL: vimeo.com/360071854

other-video

Any other video platform

URL column: Full embed URL (e.g., https://peertube.tv/w/...)

⚠️ Use the full video URL. Embedding depends on the platform's support.

post

Blog post or Facebook post (shown in Posts tab)

URL column: Full URL of the blog/post
Facebook: https://www.facebook.com/share/p/1FkYn1GL29/
Blog: https://example.com/blog/article

ℹ️ Facebook posts are embedded. Other posts show a link preview card.

Tips

  • Set Protected to Yes to require login to view the content
  • Title and Desc are optional for all types
  • Start Time only works with YouTube videos (in seconds)
  • For other-video, use the full embeddable URL
  • For post, use the full URL of the blog or post
  • For facebook-share, paste the share link as-is — it resolves automatically
  • Videos appear in the Videos tab, posts in the Posts tab
