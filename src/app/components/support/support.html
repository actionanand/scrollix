Scrollix setup

Data Entry Guide

Use one row per item in the Google Sheet. Videos appear in the Videos tab, and rows with type post appear in the Posts tab.

Google Sheet Columns

Col Field Required Description
A S No Yes Serial number.
B Type Yes Content type such as youtube, instagram, or post.
C URL Yes Video ID, share link, or full post/blog URL depending on the type.
D Protected Yes Use Yes to require login, or No for public content.
E Title No Display title.
F Desc No Description text.
G Start Time No YouTube start time in seconds.
H Resolved URL/ID No Optional resolved Facebook URL or numeric reel/video ID.

App Config

  • SCROLLIX_CONFIG.postsPerPage controls Posts pagination. Current value: 10.
  • SCROLLIX_CONFIG.videosPerPage controls Videos pagination. Current value: 6.
  • SCROLLIX_CONFIG.offlinePostLimit controls Android offline saves. Current value: 5.
  • ANDROID_POST_EXTERNAL_APPS controls post URLs that open natively instead of in-app.

Supported Types

youtube

Use the YouTube video ID, for example K6o9JTcPgOA.

Column G can contain a start time such as 85.

youtube-short

Use the Shorts ID from youtube.com/shorts/ID.

instagram

Use the Instagram post or reel code, for example DXHprmqgQQK.

facebook

Use the numeric Facebook reel/video ID, for example 1646510169815130.

facebook-reel

Same handling as facebook; use the numeric reel ID.

facebook-share

Paste the full share URL, for example https://www.facebook.com/share/v/....

Column H can hold the resolved numeric ID when needed.

dailymotion

Use the Dailymotion video ID, for example x5jnrro.

vimeo

Use the Vimeo numeric ID, for example 360071854.

other-video

Use a full embeddable video URL. Playback depends on the platform.

post

Use the full blog or social post URL.

Facebook post share links such as https://www.facebook.com/share/p/1FkYn1GL29/ are valid.

In the Android app, normal blogs open in the Scrollix in-app browser. URLs matching ANDROID_POST_EXTERNAL_APPS in the environment, currently facebook and instagram, open directly through Android so the native app can handle them.

Post Opening

  • Web opens posts in the browser as usual.
  • Android shows a Posts toggle: In-app browser or Default browser.
  • Facebook and Instagram post URLs skip the in-app browser based on the environment list.
  • Add more app names to ANDROID_POST_EXTERNAL_APPS when a site should open natively.
  • Android can save up to SCROLLIX_CONFIG.offlinePostLimit posts locally.
  • Use Show offline posts to list saved posts and open them from local content.

Shareable Video Links

  1. Short IDs, such as K6o9JTcPgOA, are used directly as the slug source.
  2. Resolved Facebook reel links use the numeric ID after /reel/.
  3. Known Facebook share links resolve before encoding.
  4. The final slug is base-36 encoded for a compact permanent URL.

Tips

  • Set Protected to Yes to require login.
  • Title and Desc are optional for all types.
  • Start Time only applies to YouTube videos.
  • For post, paste the full URL of the blog or social post.
  • For facebook-share, paste the share link as-is; column H is optional fallback.
